# Akwaba — Résidences en Côte d'Ivoire

Maquette UI/UX interactive d'une plateforme de réservation de résidences en Côte d'Ivoire
(Assinie-Mafia, Grand-Bassam, Abidjan, Yamoussoukro, Man, Sassandra, San-Pédro).

Parcours : accueil → destination → calendrier → voyageurs → résultats → fiche logement → réservation.

- Démo en ligne : https://elnino1er.github.io/Residences/
- Démo automatique : https://elnino1er.github.io/Residences/#demo

HTML / CSS / JavaScript, sans dépendance.
